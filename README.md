# NINJA

**NINJA** is a portable Linux operations and learning toolkit built with Bash.

It combines Linux+ command practice with practical system administration tools, making it useful both as a learning environment and a daily Linux toolkit.

## Features

* 📚 Structured Linux+ command cheat sheet
* 🎨 Persistent terminal themes
* 💾 Automated backups
* ♻️ Restore and rollback protection
* 🔐 SHA-256 backup verification
* 📦 Optional dependency/library backups
* 🔎 Fast command reference with `less`
* 🐧 Designed for both WSL and real Linux systems
* 🛠️ Built for future automation and AutoOps/IaC development

## Commands

```bash
ninja
ninjaedit
ninjareadme
ninjatheme
ninjabackup
ninjarestore
bashrl
```

## Philosophy

> Learn the command. Use the command. Automate the command.

NINJA is designed to build real Linux command-line muscle memory while gradually developing a reusable administration toolkit.

## Status

**Active Development**

Current focus: Linux+, system administration, portability, automation, and reliable backup/restore workflows.

## Security

Never include personal `.bashrc` files, SSH keys, passwords, API keys, private backups, or other sensitive configuration in a public repository.
