05. REGEX
================================================================================

^                               Start of line
$                               End of line
.                               Any single character
*                               Zero or more
+                               One or more
?                               Zero or one
{n}                             Exactly n
{n,m}                           Between n and m
[...]                           Character class
[^...]                          Negated character class
(...)                           Capture group
|                               OR
\                               Escape special character
[[:space:]]                     Whitespace
[[:digit:]]                     Digit
[[:alpha:]]                     Letter
[[:alnum:]]                     Letter or digit

^root:                          Begins with root:
:error:                         Contains :error:
^[0-9]+$                        Digits only
^[[:space:]]*$                 Blank / whitespace-only line
(error|fail|denied)             Match any listed word

grep -E '^(root|sshd):' /etc/passwd
grep -E 'fail|error|denied' /var/log/auth.log

BASH REGEX
[[ "$var" =~ ^[0-9]+$ ]]
[[ "$var" =~ ^[a-zA-Z0-9._-]+$ ]]

Remember:
    grep        Search text
    sed         Transform text
    awk         Process fields / records
    regex       Pattern matching language
